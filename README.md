# Калькулятор XAUUSD — Telegram Mini App

Состав:
- `index.html` — приложение (публикуется через GitHub Pages: https://jznb1111-lab.github.io/gold-calc/), один файл без сборки. Четыре вкладки: Лот, Позиция (с тейк-профитом и риск/прибыль), Маржа (с плечом), Пипс. Цена золота подставляется автоматически (gold-api.com), введённые значения сохраняются.
- `bot/bot.py` — бот: /start с кнопками, кнопка меню «Калькулятор», база пользователей (SQLite, файл `bot/users.db`), команды `/stats` и `/broadcast` для админов.

Настройки приложения — в начале `<script>` в `index.html`:
| Параметр | Что это |
|---|---|
| `REF_LINK` | реферальная ссылка (уже вписана) |
| `CHANNEL_LINK` | ссылка на канал (уже вписана) |
| `APP_LINK` | прямая ссылка на приложение (шаг 4). Пока пусто — кнопка «Поделиться» скрыта |

## Шаг 1. Создать бота в @BotFather
1. @BotFather → `/newbot` → имя и username (на `bot`).
2. Сохраните **токен**. Никому его не показывайте.

## Шаг 2. Приложение на GitHub Pages
Приложение публикуется из этого репозитория (ветка `main`, корень) по адресу
**https://jznb1111-lab.github.io/gold-calc/** — это **WEBAPP_URL**.
После любых правок `index.html` в ветке `main` сайт обновляется примерно через минуту.

## Шаг 3. Запустить бота на компьютере
Нужен Python 3.10+.
```bash
cd bot
pip install -r requirements.txt
copy .env.example .env      # на Mac/Linux: cp .env.example .env
# впишите в .env BOT_TOKEN и WEBAPP_URL
python bot.py
```
Затем напишите боту `/myid`, впишите полученное число в `ADMIN_IDS` в `.env` и перезапустите бота — станут доступны `/stats` и `/broadcast`.

Бот отвечает, пока запущен скрипт и включён компьютер. Пользователи, которые писали боту, пока он был выключен, запишутся в базу, когда бот снова запустится (Telegram хранит такие сообщения до суток).
**Не удаляйте `bot/users.db`** — это ваша база пользователей для рассылок.

## Шаг 4. Прямая ссылка на приложение (для «Поделиться» и для постов)
@BotFather → `/newapp` → выберите бота → укажите WEBAPP_URL и короткое имя, например `calc`.
Получите `https://t.me/ВАШ_БОТ/calc`. Впишите её в `APP_LINK` в `index.html` и перезалейте файл.

Ссылка может сразу открывать нужную вкладку: `https://t.me/ВАШ_БОТ/calc?startapp=margin` (варианты: `lot`, `pos`, `margin`, `pip`).

## Работа с ботом
- **Метки источников.** Ставьте в разных местах разные ссылки: `https://t.me/ВАШ_БОТ?start=channel`, `?start=ads1` и т.д. `/stats` покажет, сколько людей пришло с каждой.
- **Рассылка.** Отправьте боту сообщение (текст, фото, видео, с кнопками — любое), ответьте на него командой `/broadcast`, подтвердите кнопкой. Тем, кто заблокировал бота, сообщение больше не отправляется.

## Формулы
- 1 лот = 100 унций; движение на $1 = $100 на лот; пипс = $0.10, пункт = $0.01.
- Размер лота = (Баланс × Риск%) / (Стоп в $ × 100), округление **вниз** до 0.01.
- Размер позиции = Риск $ / (|Вход − Стоп| × 100), округление вниз до 0.01.
- Маржа = Лот × 100 × Цена / Плечо. «Нужен депозит от» = Маржа + Риск по стопу.
