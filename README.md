# Калькулятор XAUUSD — Telegram Mini App

Состав:
- `index.html` — приложение (публикуется через GitHub Pages: https://jznb1111-lab.github.io/gold-calc/), один файл без сборки. Четыре вкладки: Лот, Позиция (с тейк-профитом и риск/прибыль), Маржа (с плечом), Пипс. Цена золота подставляется автоматически (gold-api.com), введённые значения сохраняются.
- `bot/bot.py` — бот: /start с кнопками, кнопка меню «Калькулятор», база пользователей (SQLite, файл `bot/users.db`), команды `/stats` и `/broadcast` для админов.

Настройки приложения — в начале `<script>` в `index.html`:
| Параметр | Что это |
|---|---|
| `REF_LINK` | реферальная ссылка (уже вписана) |
| `CHANNEL_LINK` | ссылка на канал (уже вписана) |
| `BOT_USERNAME` | никнейм бота (@Lotcalcubot), подписывается в конце сводки «Поделиться» |

## Шаг 1. Создать бота в @BotFather
1. @BotFather → `/newbot` → имя и username (на `bot`).
2. Сохраните **токен**. Никому его не показывайте.

## Шаг 2. Приложение на GitHub Pages
Приложение публикуется из этого репозитория (ветка `main`, корень) по адресу
**https://jznb1111-lab.github.io/gold-calc/** — это **WEBAPP_URL**.
После любых правок `index.html` в ветке `main` сайт обновляется примерно через минуту.

## Шаг 3. Запустить бота на компьютере
Нужен Python 3.10+.
```bash
cd bot
pip install -r requirements.txt
copy .env.example .env      # на Mac/Linux: cp .env.example .env
# впишите в .env BOT_TOKEN и WEBAPP_URL
python bot.py
```
Затем напишите боту `/myid`, впишите полученное число в `ADMIN_IDS` в `.env` и перезапустите бота — станут доступны `/stats` и `/broadcast`.

Бот отвечает, пока запущен скрипт и включён компьютер. Пользователи, которые писали боту, пока он был выключен, запишутся в базу, когда бот снова запустится (Telegram хранит такие сообщения до суток).
**Не удаляйте `bot/users.db`** — это ваша база пользователей для рассылок.

## Шаг 3б. Запуск в фоне (без чёрного окна, с автозапуском)
Когда бот заработал по шагу 3, закройте окно с ним и сделайте так:
1. В папке `bot` дважды щёлкните **`install_autostart.bat`**.
   Скрипт поставит библиотеки, создаст задание в Планировщике Windows и сразу запустит бота.
2. Всё. Бот работает в фоне, сам стартует при входе в Windows и сам перезапускается, если упал.

Файлы для управления (все в папке `bot`, запуск двойным щелчком):
| Файл | Что делает |
|---|---|
| `start_bot.bat` | запустить бота |
| `stop_bot.bat` | остановить бота |
| `show_log.bat` | открыть журнал работы `bot.log` (ошибки, перезапуски) |
| `uninstall_autostart.bat` | остановить и убрать автозапуск |

**Где увидеть бота:**
- Диспетчер задач → вкладка **«Подробности»** → процесс **`pythonw.exe`**. На вкладке «Процессы» он в разделе «Фоновые процессы» под именем Python.
- Планировщик заданий → задание **`GoldCalcBot`** (там видно, запущено ли и когда стартовало).

Если поменяли `.env` или обновили `bot.py` — запустите `stop_bot.bat`, затем `start_bot.bat`.
Бот работает, пока компьютер включён и вы вошли в Windows. В спящем режиме бот не отвечает.

## Вариант: бот на бесплатном хостинге Railway (для теста)
Railway бесплатно и без банковской карты: первые 30 дней — пробные $5 (бот работает без перерывов), дальше бесплатный план $1 в месяц (для маленького бота может не хватить на весь месяц — тогда бот остановится до начала следующего месяца). Для теста этого достаточно, потом можно перейти на платный план или свой сервер.

⚠️ Бот должен работать **в одном месте**. Перед запуском на Railway остановите бота на компьютере (`uninstall_autostart.bat`), иначе две копии будут мешать друг другу.

1. Зайдите на **railway.com** → **Login** → войдите через **GitHub**.
2. **New Project** → **Deploy from GitHub repo** → выберите `gold-calc` (если репозитория нет в списке — нажмите *Configure GitHub App* и дайте доступ к нему).
3. Откройте появившийся сервис → **Settings**:
   - **Root Directory** → впишите `bot`.
4. Вкладка **Variables** → добавьте:
   | Имя | Значение |
   |---|---|
   | `BOT_TOKEN` | токен от @BotFather |
   | `WEBAPP_URL` | `https://jznb1111-lab.github.io/gold-calc/` |
   | `ADMIN_IDS` | ваш Telegram ID (из команды `/myid`) |
   | `DB_PATH` | `/data/users.db` |
5. Чтобы база пользователей не пропадала при обновлениях: на схеме проекта нажмите правой кнопкой на сервис → **Attach Volume** → Mount path: `/data`.
6. Нажмите **Deploy** (или он начнётся сам). Во вкладке **Deployments → View Logs** должно появиться `Start polling`. Напишите боту `/start`.

Обновление: всё, что попадает в репозиторий на GitHub, Railway разворачивает заново сам.
Остановить: Settings → внизу **Remove service** (или поставьте на паузу через меню сервиса).

## Шаг 4. Прямая ссылка на приложение (для «Поделиться» и для постов)
@BotFather → `/newapp` → выберите бота → укажите WEBAPP_URL и короткое имя, например `calc`.
Получите `https://t.me/ВАШ_БОТ/calc`. Впишите её в `APP_LINK` в `index.html` и перезалейте файл.

Ссылка может сразу открывать нужную вкладку: `https://t.me/ВАШ_БОТ/calc?startapp=margin` (варианты: `lot`, `pos`, `margin`, `pip`).

## Работа с ботом
- **Метки источников.** Ставьте в разных местах разные ссылки: `https://t.me/ВАШ_БОТ?start=channel`, `?start=ads1` и т.д. `/stats` покажет, сколько людей пришло с каждой.
- **Рассылка.** Отправьте боту сообщение (текст, фото, видео, с кнопками — любое), ответьте на него командой `/broadcast`, подтвердите кнопкой. Тем, кто заблокировал бота, сообщение больше не отправляется.

## Формулы
- 1 лот = 100 унций; движение на $1 = $100 на лот; пипс = $0.10, пункт = $0.01.
- Размер лота = (Баланс × Риск%) / (Стоп в $ × 100), округление **вниз** до 0.01.
- Размер позиции = Риск $ / (|Вход − Стоп| × 100), округление вниз до 0.01.
- Маржа = Лот × 100 × Цена / Плечо. «Нужен депозит от» = Маржа + Риск по стопу.
